FEATURES:
Contextual Analysis: Uses the bert-base-uncased model to extract deep linguistic features from text.

RAG-based Moderation: Employs a Retrieval-Augmented Generation (RAG) style logic to compare song meanings against safety guidelines.

Cosine Similarity Scoring: Measures how closely lyrics align with specific safety categories (violence, language, etc.) using vector math.

Full-Stack Integration: Features a high-performance FastAPI backend and a modern Glassmorphism Web UI.
